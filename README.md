## Descripción del sistema
CoopeTica R.L. es una cooperativa de ahorro y crédito con varias sucursales. Este sistema de escritorio, hecho en Java con interfaz gráfica Swing, centraliza la información de sucursales, asociados, aportes, cuentas de ahorro y corriente, préstamos y cuotas. Guarda todo en archivos de texto para que la información no se pierda al cerrar el programa, y genera reportes que se pueden guardar en un archivo.

## Requisitos
- JDK 25
- Apache NetBeans 32

## Instrucciones de ejecución
1. Clonar el repositorio: `git clone https://github.com/chavarriaaa/bis04-coopetica-chavarria-fonseca.git`
2. Abrir NetBeans y elegir **File → Open Project**, seleccionando la carpeta clonada.
3. Verificar que el proyecto use JDK 25 (clic derecho en el proyecto → **Properties → Libraries**).
4. Ejecutar la clase principal (añadir los nombres exactos de cada clase mencionada) con **Run Project**.
5. Se abre la ventana principal del sistema.
